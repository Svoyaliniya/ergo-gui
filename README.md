📌 Описание проекта

VueCraft — это лёгкое веб-приложение на Vue 3 + Vite с интеграцией GrapesJS. Оно превращает пустой Vue-проект в удобный drag-and-drop редактор, где можно собирать интерфейсы из блоков текста, изображений, видео, разделителей и интервалов прямо в браузере.

⸻

✨ Возможности
	•	Современный стек: Vue 3 + Vite
	•	Встроенный GrapesJS для визуального редактирования
	•	Удобный drag-and-drop интерфейс
	•	Базовые блоки: текст, видео, разделитель, интервал
	•	Возможность добавлять свои компоненты
	•	Простая и расширяемая структура проекта

⸻

🚀 Для кого
	•	Разработчики, которые хотят быстро подключить GrapesJS к Vue
	•	Дизайнеры и контент-менеджеры, которым нужен визуальный редактор
	•	Для обучения и экспериментов с Vue + GrapesJS

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
